# asiject

프론트엔드 중심으로 화면, 상태, REST API 연동을 맡습니다. React·TypeScript가 주력이고, 관리자 화면과 폼·인증 흐름을 구현합니다.

## 대표 작업

- **[C-ON Homepage](https://github.com/asiject/c-on-homepage-portfolio)** — 공식 홈과 Admin SPA. 공지·FAQ·문의 CRUD, Mock/실서버 API 전환. [Live](https://c-on-homepage-portfolio.vercel.app)
- **[THE FOUR](https://github.com/asiject/thefourkorea-portfolio)** — B2B 훈련 플랫폼의 사용자·강사·관리자, 소셜 로그인, 신청 폼, S3·CloudFront 배포. 공개본은 NDA를 분리한 패턴 샘플이고, 실행 데모는 신청 폼입니다.
- **[Bridge Card](https://github.com/asiject/bridge-card-portfolio)** — ZOOM 아이스브레이킹 카드. 플립, 라이트/딥 모드, 타이머, 셔플. [Live](https://bridge-card-portfolio.vercel.app)
